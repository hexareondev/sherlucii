# Сайт-портфолио художника

Статический сайт: галерея работ по категориям, просмотр работы на весь экран, ссылка на каждую работу, блок «Обо мне». Работает на бесплатном GitHub Pages, редактируется через бесплатную админку Pages CMS — без кода.

## Что внутри

```
index.html          страница сайта
assets/style.css    оформление
assets/app.js       галерея, фильтры, просмотр работ
content/works.json  список работ (редактируется в админке)
content/site.json   имя, текст «Обо мне», контакты, категории
images/             фото работ (сюда же админка загружает новые)
.pages.yml          настройки админки Pages CMS
.nojekyll           служебный файл для GitHub Pages
```

## 1. Выложить сайт на GitHub Pages

1. Зарегистрируйтесь на github.com (если ещё нет аккаунта).
2. Нажмите **New repository**. Название, например, `portfolio`. Тип — **Public** (бесплатный GitHub Pages работает с публичными репозиториями). Создайте.
3. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** распакованной папки `portfolio` (не саму папку, а то, что внутри). Нажмите **Commit changes**.
   - Файлы `.pages.yml` и `.nojekyll` начинаются с точки и могут быть скрыты. На Mac их показывает сочетание `Cmd + Shift + .` в Finder, на Windows — «Вид → Скрытые элементы». Без `.pages.yml` админка не узнает, какие поля показывать.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/portfolio/`. Этой ссылкой можно делиться.

## 2. Подключить админку Pages CMS

1. Откройте https://app.pagescms.org и войдите через GitHub.
2. Разрешите Pages CMS доступ к репозиторию `portfolio` (можно выбрать только его).
3. Откройте репозиторий в Pages CMS. Слева появятся разделы **Работы** и **Профиль**.

Добавлять работы может только тот, у кого есть доступ к репозиторию на GitHub. Посетители сайта видят только галерею.

## 3. Как добавить работу

1. В Pages CMS откройте **Работы** и нажмите кнопку добавления нового элемента (**Add**) внизу списка.
2. Заполните название, выберите категорию, загрузите главное фото и, если нужно, дополнительные (детали, процесс, другие ракурсы).
3. Нажмите **Save**. Через 1–2 минуты работа появится на сайте.

Полезное:
- **Порядок работ** на сайте такой же, как в списке в админке — перетаскивайте записи, чтобы поменять.
- **«Показать на обложке»** — отмеченная работа попадёт в большую шапку сайта.
- Примеры (`sample-1…8.jpg`, `avatar.jpg`) удалите: сначала записи в **Работах**, затем сами файлы в разделе **Media**. Своё фото и текст о себе замените в **Профиле**.

## 4. Как добавить новую категорию

Категория прописана в двух местах:
1. В **Профиле** → поле **Категории** — добавьте название (так появится вкладка на сайте).
2. В файле `.pages.yml` на GitHub: найдите строку `values: [Кастом, Рисунки, Скетчи, Другое]` и допишите новую категорию через запятую (так она появится в выпадающем списке в админке). Редактировать файл можно прямо на github.com — значок карандаша.

## 5. Фото: размер и вес

GitHub Pages вмещает около 1 ГБ на сайт, и тяжёлые фото медленно грузятся с телефона. Перед загрузкой уменьшайте снимки:
- длинная сторона — до 2000 px;
- вес — до 1 МБ, лучше 300–600 КБ;
- удобный бесплатный инструмент — https://squoosh.app (формат JPEG или WebP, качество 75–85).

## 6. Свой домен (по желанию)

Если купите домен (например `imya.art`), подключите его в **Settings → Pages → Custom domain** и следуйте подсказкам GitHub. Сайт продолжит работать без изменений.

## Посмотреть сайт у себя на компьютере

Если просто открыть `index.html` двойным щелчком, браузер не загрузит работы из-за ограничений безопасности. Запустите в папке сайта:

```
python3 -m http.server 8000
```

и откройте http://localhost:8000
